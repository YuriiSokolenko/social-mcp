# Implement TikTok OAuth connection and reconnect through Web Admin

## Scope and acceptance
## Goal
Implement TikTok account connection through the Web Admin using the shared admin/auth/storage architecture and the TikTok OAuth adapter contract.

## Acceptance criteria
- Login Kit/OAuth initiated from the Accounts page.
- Secure callback/state handling bound to the admin session.
- Server-side token exchange with TikTok Login Kit.
- Encrypted token persistence with granted scopes and expiry metadata.
- Reconnect flow for an already-connected TikTok account.
- Expose only capabilities actually granted by the connected account.
- Tests with mocked TikTok API boundaries (no live calls, no production writes); run pytest and Ruff.

## Out of scope
No new OAuth flow for Threads, no live TikTok API calls in CI, no credential disclosure.

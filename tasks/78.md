# Define TikTok OAuth adapter and capability contract

## Scope and acceptance
## Goal
Define the TikTok Login Kit OAuth adapter interface and scope-to-capability mapping that the Web Admin and MCP layers will share for TikTok account connection.

## Acceptance criteria
- Define TikTok OAuth scope constants and the authorization/token-refresh endpoints used by Login Kit.
- Define the TikTok adapter interface: authorization URL construction, server-side token exchange, and refresh token handling.
- Define the TikTok scope-to-capability mapping (profile, video, statistics) consistent with docs/PROJECT_CONTEXT.md and the MCP capability contract.
- Document TikTok account state representation (scopes, expiry, platform identifier).
- Add focused tests for the contract with mocked boundaries; run Ruff.

## Out of scope
No Web Admin routes, no OAuth execution, no live TikTok API calls, no credential handling.

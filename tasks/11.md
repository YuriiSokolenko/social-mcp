# Test SQLite connected-account storage

## Goal

Establish deterministic test coverage for the existing SQLite connected-account store before the storage layer is expanded.

## Scope

Use a temporary SQLite database and fake, non-production token bytes. Cover account persistence, encrypted token-byte round trips, updating an existing (platform, external_account_id) pair without duplication, and listing accounts. Do not call Threads or TikTok APIs.

## Acceptance notes

Follow the acceptance criteria in GitHub issue #11. This task adds focused storage tests and any minimal correction needed to make the documented storage behavior work; it does not add OAuth or new product capabilities.
